# 查询入口覆盖矩阵

证据等级与 Agent 线路是两个独立维度。`A/B/FR/C/X` 只表示取证情况；`可执行/条件可执行/页面会话依赖/不可执行` 的定义见[文档首页](./README.md#agent-线路可执行性)。`辅助` 表示非独立菜单页的下拉或树查询。

## 商品与品牌

| 菜单/能力 | 证据 | Agent 线路 | 说明 |
|---|---|---|---|
| [商品管理](./products.md#快准商品列表) | A | 页面会话依赖 | 原始 `data` 为 `kziv`；逻辑 schema 已确认，但纯 HTTP Agent 没有页面 `SYSTEM.k` |
| [三方商品管理](./products.md#三方商品列表) | A | 页面会话依赖 | 同样依赖页面解码，不能把逻辑行字段当作普通 HTTP JSON |
| [套包管理](./products.md#套包分页列表) | A | 条件可执行 | 无商品条件的分页列表可用；`inv_ids` 多选和候选解码未闭环 |
| [报价规则管理](./products.md#报价规则分页列表) | A | 可执行 | 规则分页列表；新增、设置、编辑、复制、删除排除 |
| [品牌列表](./shared.md#品牌列表) | A 辅助 | 可执行 | 优先使用可按 `totalsize` 翻页的 GET |
| [快准分类树](./shared.md#快准商品分类树) | A 辅助 | 可执行 | 销售明细 `kzCategoryIds` 的叶节点 ID 数组来源 |
| [三方分类/业务类别](./shared.md#三方类别业务类别列表) | A 辅助 | 条件可执行 | 三种只读 action 的请求形态已确认；消费参数仍须按页面分别绑定 |
