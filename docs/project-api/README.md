# kzmall-plus 项目 API 文档

本目录只记录 kzmall-plus 自有的 Worker API、认证方式、错误协议和运行边界，不重复收录快准车服上游业务接口。快准上游查询路径、筛选参数和响应字段统一见[快准接口文档](../api/README.md)。

## 文档导航

- [AI Agent 凭证网关](./agent-gateway.md)：`/api/<快准接口路径>` 的 Agent 认证代理，以及 `/api/agent-credentials*` 凭证管理接口。

## 边界约定

- 本目录记录由本仓库实现和维护的接口契约。
- `../api/` 记录快准车服上游接口契约；项目代理只负责认证、隔离和转发，不在这里复制业务字段。
- 新增项目自有接口时，应在本目录补充请求、响应、鉴权、错误码及副作用说明。
